# gitt-shuffle

## 番号付きプレゼント選び

ゲームの勝者から箱番号を選び、最後にプレゼントの持ち主を発表するゲームです。
公開に必要なファイルは、`index.html`だけです。

### 当日の流れ

1. 参加者の名前を登録します。
2. 「箱を選ぶ順番」で「ゲームの勝者をその都度選ぶ」を選びます。
3. 「箱を用意して、ゲーム開始！」を押します。
4. じゃんけんなどのゲームをし、勝った人の名前を画面で選びます。
5. 勝った人が、好きな箱番号を1つ選びます。
6. 画面には、選んだ人と箱番号だけが表示されます。
7. 「次の人へ」を押し、全員が選ぶまで繰り返します。
8. 最後に「全員の結果を発表！」を押します。
9. 矢印を確認し、プレゼントを渡します。

プレゼントは、最後の発表まで各自で持っておきます。  
途中では、持ち主や受け渡し先は表示しません。  
途中の履歴にも、選んだ人と箱番号だけを表示します。  
コピー機能は、最後の発表後に表示します。  
「アプリでランダムに決める」を選ぶと、選ぶ順番をアプリが決めます。  

結果は、「渡す人 → 受け取る人」の向きで表示します。  
最後の画面では、結果が順に現れ、矢印に沿ってプレゼントが動きます。  
「アニメーションをもう一度」で、同じ結果を再表示できます。  
この操作で抽選結果は変わりません。  
履歴とコピーした結果も、同じ矢印の向きです。  

「お試し入力」でも遊べます。  
2〜60人に対応します。  
奇数でも偶数でも、全員が1つずつ渡し、1つずつ受け取ります。
